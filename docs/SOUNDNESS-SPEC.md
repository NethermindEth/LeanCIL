# Specification baseline

LeanCIL models ECMA-335 6th edition (June 2012) as amended by the
[ECMA-335 augments](https://github.com/dotnet/runtime/blob/b22bfee2010118c58ae143c3b8a1aaee3d0c8c4c/docs/design/specs/Ecma-335-Augments.md)
that Microsoft maintains in dotnet/runtime, pinned at commit
`b22bfee2010118c58ae143c3b8a1aaee3d0c8c4c`. Where the two disagree, the augment is the
reference. Each augment area below is either modeled, rejected before or during checked
execution, or not applicable to the extracted semantics.

A model fault (`invalidState`, a memory fault or `unsupported`) is never a successful execution
and never a named CLR exception, so "rejected at execution" excludes the path from every proof.

| Augment area | LeanCIL status | Where enforced |
| --- | --- | --- |
| Signatures: TypeSpec after `CLASS`/`VALUETYPE` or a custom modifier | Rejected or not applicable. Mono.Cecil decodes signatures (a trusted component). The one admitted modifier must name a non-TypeSpec `System.Runtime` `InAttribute`. | [`InReferences.Unwrap`](../Extractor/InReferences.cs) |
| Signatures: custom modifiers in more places, `BYREF` before modifiers | Rejected except `modreq(InAttribute)` directly before a modifier-free `BYREF` parameter. `BYREF CMOD T`, `modopt` and other `modreq` forms fail; locals, returns and fields with modifiers are unsupported types; typed contract signatures admit none. | [`InReferences.Unwrap`](../Extractor/InReferences.cs), [`MetadataValidation.Type`](../Extractor/MetadataValidation.cs), [`ContractMethodMetadata.RejectModifiers`](../Extractor/ContractMethodMetadata.cs); mutations [`"nested"`](../Tests/ConstrainedCalls.cs), [`"modopt"`](../Tests/ConstrainedCalls.cs) and [`"other-modreq"`](../Tests/ConstrainedCalls.cs) |
| Heap sizes | Not applicable: metadata heaps are decoded by Mono.Cecil. | [Trusted components](SOUNDNESS.md#trusted-components-and-deployment-assumptions) |
| Metadata merging | Not applicable: the CLI does not merge metadata. An extraction reads the selected assembly and each pinned `--reference` as separate modules, keeps type identities assembly-qualified and rejects a method signature shared by two of them. | [`PinnedAssemblies`](../Extractor/PinnedAssemblies.cs), [`MetadataValidation.Validate`](../Extractor/MetadataValidation.cs); [pinned references](SOUNDNESS-EVIDENCE.md#pinned-referenced-assemblies) |
| Metadata logical format (InterfaceImpl order) | Not applicable: constrained resolution tests interface membership and rejects ambiguity, so declaration order cannot change the result. | [`resolveConstrained`](../CIL/Extraction/Dispatch.lean) |
| Module initializer | Not modeled; static constructors, including `<Module>..cctor`, are never extracted. Methods on a type with a static constructor need `--assume-initialized`; for a generic class the open name, such as ``Seeded`1``, assumes every instantiation's initializer ran. A referenced assembly's type with one is rejected; a readonly static stored by any other module method, including a module initializer, is rejected. | [`MetadataValidation.Validate`](../Extractor/MetadataValidation.cs), [`StaticValues.Compute`](../Extractor/StaticValues.cs); [static initialization assumption](SOUNDNESS.md#trusted-components-and-deployment-assumptions) |
| Default interface methods | Modeled only for static virtual slots: when the receiver records no `MethodImpl` override and has no public same-signature method, `constrained. T; call` runs the most specific interface-level body, the runtime's rule: among the slot's own body and every interface `MethodImpl` of the slot on an interface of the receiver, the one whose interface inherits every other candidate's, instantiated at its closed interface and the site's method type arguments. A recorded override wins; an unrecorded candidate beside a slot body is ambiguous and rejected. Two unrelated overriding interfaces (no unique winner) and a re-abstracting winner are rejected. The receiver's interface list must be closed under inheritance and fully present in the dispatch catalog, so a receiver with an interface outside the extracted and pinned assemblies is rejected. Instance default methods are rejected, since their body would need a boxed receiver. | [`resolveConstrained`](../CIL/Extraction/Dispatch.lean), [`mostSpecific_spec`](../CIL/Extraction/Dispatch.lean), [`ConstrainedCalls.Resolve`](../Extractor/ConstrainedCalls.cs); tests [`default_interface_slot_rejected`](../Tests/ConstrainedEvidence.lean), [`static_default_valid`](../Tests/ConstrainedEvidence.lean), [`static_override_precedes_default`](../Tests/ConstrainedEvidence.lean), [`static_default_ambiguity_rejected`](../Tests/ConstrainedEvidence.lean), [`static_derived_body_valid`](../Tests/ConstrainedEvidence.lean), [`static_interface_closure_rejected`](../Tests/ConstrainedEvidence.lean), [`derived_override_valid`](../Tests/ConstrainedEvidence.lean), [`most_derived_body_valid`](../Tests/ConstrainedEvidence.lean), [`diamond_rejected`](../Tests/ConstrainedEvidence.lean), [`reabstraction_rejected`](../Tests/ConstrainedEvidence.lean) |
| Static interface methods | Modeled: `constrained. T; call` resolves a static virtual slot of a directly implemented interface, including a generic method slot, to `T`'s static implementation or to the most specific interface-level body, called without a receiver. `T` and the interface may come from different extracted or pinned assemblies; every dispatch catalog entry names its pin, which must scope its type. Method type arguments must be closed and match the slot's arity, and the emitted instance must carry them exactly. `callvirt` on a static slot, `call` on an instance slot, `constrained. ldftn`, generic instance slots and static slots on generic struct receivers fail. | [`constrainedSiteWindow`](../CIL/Extraction/Constrained.lean), [`resolveConstrained`](../CIL/Extraction/Dispatch.lean), [`ConstrainedCalls.Resolve`](../Extractor/ConstrainedCalls.cs); tests [`static_call_valid`](../Tests/ConstrainedEvidence.lean), [`call_opcode_mismatch_rejected`](../Tests/ConstrainedEvidence.lean), [`static_slot_mismatches_rejected`](../Tests/ConstrainedEvidence.lean), [`static_default_arguments_rejected`](../Tests/ConstrainedEvidence.lean), [`cross_pin_implementation_valid`](../Tests/ConstrainedEvidence.lean), [`unpinned_catalog_rejected`](../Tests/ConstrainedEvidence.lean) |
| Constant static flag getters | Modeled for branch selection only: a parameterless static call, plain or `constrained. T; call`, to a program method returning `System.Boolean` whose own feature certificate shows the same 0 or 1 on top of the stack at every reachable `ret`, and at least one reachable `ret`, supplies that word to feature flow, which prunes the block it rules out. The getter may compute its word from other such calls, type tests and feature tests at any depth. The call is still emitted, and the callee's certificate is validated by its own obligation in the same whole-program certificate. Pruned pcs are `.unsupported` holes with no step, so a wrong word, including a self-consistent claim on a call cycle, only sends execution into a hole: it can make a successful outcome unreachable, never provable. Imports and calls past the program are never constant; the extractor also leaves cycles, tail calls and certificates without one 0 or 1 word unknown. The getter's type initialization follows the `--assume-initialized` rule for extracted methods. | [`constantReturn`, `calleeConstant`](../CIL/Extraction/Features.lean), [`evidenceConstants`](../CIL/Extraction/Translation.lean), [`ConstantReturns`](../Extractor/ConstantReturns.cs); tests [`forged_constant_rejected`](../Tests/ConstantCalls.lean), [`constant_swap_rejected`](../Tests/ConstantCalls.lean), [`constant_body_rejected`](../Tests/ConstantCalls.lean) |
| Covariant return types | Rejected: class instance methods and unconstrained virtual dispatch are unsupported, and an interface override must match the slot signature exactly. | [`MetadataValidation.Validate`](../Extractor/MetadataValidation.cs), [`ConstrainedCalls.Resolve`](../Extractor/ConstrainedCalls.cs), [`resolveConstrained`](../CIL/Extraction/Dispatch.lean) |
| Function pointer type identity | Stricter than the augment: only the default managed convention is callable, compared exactly; unmanaged conventions are rejected. | [`managedSignature`](../CIL/Extraction/Generics.lean), [`ManagedPointers.Validate`](../Extractor/ManagedPointers.cs) |
| `conv.ovf.<to>.un` with float source | Not reachable: values have no floating-point form, float constants and conversions are untranslated, and scalar flow requires an integer operand. | [`Value`](../CIL/Types.lean), [`convertInteger`](../CIL/IntegerArithmetic.lean), [`InstructionTranslation.TranslateCore`](../Extractor/InstructionTranslation.cs); [`floatRaw`](../Tests/ScalarEvidence.lean) cases |
| Ref fields | Rejected: a byref field type is unsupported. `Span<T>` and `ReadOnlySpan<T>` are runtime-modeled views, not structs with a ref field. | [`MetadataValidation.AggregateLayout`](../Extractor/MetadataValidation.cs), [`SpanView`](../CIL/Safety/SpanViews.lean) |
| Managed pointers: null and one past the end | Modeled conservatively. Null is a managed-reference value that can be stored, passed and compared; dereferencing or offsetting it is a `nullDereference` model fault, not the augment's `NullReferenceException`. End positions form only as declared sentinels and grant no access. | [`ManagedReference`](../CIL/Safety/Memory.lean), [`validPosition`](../CIL/Safety/Memory.lean), [`access`](../CIL/Safety/Memory.lean), [`referenceAt`](../CIL/Safety/InstructionMemory.lean), [`instruction`](../CIL/Safety/InstructionMemory.lean), [`ExecutionFault.clrException`](../CIL/Safety/RuntimeExceptions.lean) |
| `RefSafetyRulesAttribute` (escaping `this`) | Not checked. The admitted subset has no `box`, so a struct receiver is always caller-owned storage and the boxing elimination the rule licenses cannot arise. | [OPCODES](OPCODES.md#unsupported-opcodes) |
| ByRefLike types in generics (`AllowByRefLike` 0x20) | Modeled: the flag is accepted and every generic method is checked as its closed instantiation. Byref-like elements cannot be heap array elements or fields of heap-storable structs. | [`MethodSpecialization.Instantiate`](../Extractor/MethodSpecialization.cs), [`byRefLikeFieldsValid`](../CIL/Extraction/Layout.lean), [`Arrays.Storage`](../Extractor/Arrays.cs) |
| Rules for IL rewriters (RVA alignment) | Modeled: the extractor rejects static data whose RVA is not a multiple of its `.pack` (1, 2, 4 or 8). It also rejects data that does not lie within one section's raw data and mapped size, and data in a section whose virtual address and file offset differ by a non-multiple of 8, since the PE format only recommends a 512-byte file alignment and CoreCLR may read an IL-only image flat, at its base plus the file offset. Mapped and converted layouts place sections at a page-aligned base plus their RVA; a flat layout's base is page-aligned for `Assembly.Load(byte[])` and files, and 64-byte or wider for single-file bundles ([loader](https://github.com/dotnet/runtime/blob/72104d3bf44e12fe7778ca4ffb0a95609fb6147d/src/coreclr/vm/peimagelayout.cpp), [bundler](https://github.com/dotnet/runtime/blob/72104d3bf44e12fe7778ca4ffb0a95609fb6147d/src/installer/managed/Microsoft.NET.HostModel/Bundle/TargetInfo.cs)). A flat image the host hands CoreCLR by external probing is used at the host's address, which is assumed 8-byte aligned (see [static storage](SOUNDNESS-RUNTIME.md#static-storage)). The descriptor's `alignment` is that packing and becomes the static allocation's layout alignment. `CreateSpan<T>` succeeds only when `sizeof(T)` divides it, which for these powers of two means `.pack >= sizeof(T)` and so an RVA that is a multiple of `sizeof(T)`; a narrower packing is an `unsupported` fault, never the success the CLR would replace with `ArgumentException`. | [`StaticData.Validate`](../Extractor/StaticData.cs), [`StaticData.RequireSectionAligned`](../Extractor/StaticData.cs), [`StaticDescriptor`](../CIL/Instructions.lean), [`staticReference`](../CIL/Safety/StaticMemory.lean), [`staticSpanAligned`](../CIL/Safety/StaticMemory.lean), [`staticInstruction`](../CIL/Safety/StaticMemory.lean), [`createSpan_aligned_at_placement`](../CIL/Safety/StaticSpanAlignment.lean); tests [`"Narrow-packing"`](../Tests/SpanTables.cs), [`"Reject-misaligned-rva"`](../Tests/SpanTables.cs) and [`"Reject-section-file-offset"`](../Tests/SpanTables.cs) |
| Checked user-defined operators | Not applicable: operators are ordinary calls resolved by token or exact runtime signature, never by name. | [RuntimeModels.cs](../Extractor/RuntimeModels.cs) |
| Atomic reads and writes | Not applicable: the model is single-threaded and `volatile.` is unsupported. | [SOUNDNESS](SOUNDNESS.md#what-verification-establishes) |
| Backward branch constraints (deleted) | Modeled: stack kinds come from a worklist over all reachable edges; every successor must see the same stack, and inconsistent joins are rejected. | [`NativeOperands.Certify`](../Extractor/NativeOperands.cs), [`ScalarFlowValid`](../CIL/Extraction/Scalars.lean); fixture [`"BackwardSwitch"`](../Tests/Loops.cs) and mutations [`"stack-height"`](../Tests/Loops.cs), [`"stack-type"`](../Tests/Loops.cs), [`"local-fact"`](../Tests/Loops.cs) and [`"stack-fact"`](../Tests/Loops.cs) |

| `newobj` for SZ arrays | Rejected: array constructors are external methods without a runtime model. | [`MetadataValidation.Validate`](../Extractor/MetadataValidation.cs), [`ImportResolution.Admit`](../Extractor/ImportResolution.cs) |
| API documentation | Not applicable: runtime methods are admitted only through exact signature models. | [Runtime assumptions](SOUNDNESS-RUNTIME.md#runtime-assumptions) |
| Debug Interchange Format | Not applicable to semantics: Portable PDB supplies local names for proofs only. | [DebugNames.lean](../CIL/DebugNames.lean) |
| Extended layout (0x18) | Rejected: aggregates must be sequential or explicit, enums and value tuples auto. This relies on Mono.Cecil's masked layout flags. | [`MetadataValidation.AggregateLayout`](../Extractor/MetadataValidation.cs), [`EnumTypes.ValidateStorage`](../Extractor/EnumTypes.cs) |
| Implicit argument coercion (int32 to `native unsigned int`) | Rejected: no implicit int32-to-native coercion exists. Call arguments, `stloc`, `starg` and `ret` require the slot's kind, and checked stores into eight-byte homes require an `i64`. Code needs an explicit `conv.i` or `conv.u`. | [`storageCompatible`](../CIL/Extraction/Scalars.lean), [`scalarTransfer`](../CIL/Extraction/Scalars.lean), [`localNumber`](../CIL/Safety/Frames.lean), [`storeTransfer`](../CIL/Safety/InstructionMemory.lean), [`otherMemoryInstruction`](../CIL/Safety/InstructionMemory.lean); tests [`no_implicit_native_coercion`](../Tests/ScalarEvidence.lean), [`native_home_rejects_int32`](../Tests/ScalarEvidence.lean) |
| Init-only static fields | Modeled: `stsfld` is never extracted, and a readonly value is admitted only when its own static constructor is the sole writer. A scalar whose stored value extraction cannot compute is admitted as unknown and read from the caller's static binding. Writes by unmodeled code are an explicit assumption. | [`InstructionTranslation.TranslateCore`](../Extractor/InstructionTranslation.cs), [`StaticValues.Compute`](../Extractor/StaticValues.cs); mutations [`"store"`](../Tests/StaticValues.cs) and [`"twice"`](../Tests/StaticValues.cs); unknown seeds [`"Opaque-guessed.lean"`](../Tests/StaticScalarValues.cs) |
