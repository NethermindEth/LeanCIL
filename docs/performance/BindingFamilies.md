# Synthetic proof binding measurements

The integer binding fixture instantiates four reviewed equality and bitwise recipes for
`scalar` and `x64-v3`. Each generated module proves the full managed signature and extracted
method equality, then applies a shared execution theorem. All eight bindings pass ordinary
certifying verification, including extraction audit and independent kernel replay.

The 2026-11-10 measurement used framework revision
`cfa8432b447861abde7a4983be4f20dcece19864` and recorded these source sizes:

| Source | Lines | Files | Bytes |
| --- | ---: | ---: | ---: |
| Maintained binding recipes | 62 | 1 | — |
| Shared execution proofs | 60 | 1 | — |
| Synthetic C# methods | 15 | 1 | — |
| Verification and measurement harness | 137 | 1 | — |
| Generated Lean bindings | 160 | 8 | 7,956 |

Line counts include comments and blank lines. Generated bytes are the actual UTF-8 file sizes.
The shared proofs, fixture methods and harness remain maintained source. These measurements
do not establish consumer line savings or remove any Lean proof obligations.

Four negative recipes change width, signedness, equality polarity or the extracted bitwise
operation. All four fail verification and leave no certificate. Reversed catalog order retains
the same generated output. Every positive certificate records its generated proof source identity.

Run the fixture with `dotnet run --file Tests/ProofBindingFamilies.cs`. An already compiled
framework checkout can be selected with `-- --framework <checkout>`. The fixture records source
counts and the framework revision in `artifacts/ProofBindingFamilies/sizes.json`, alongside the
positive and negative verification results. The observed eight-binding verification duration was
141.43 seconds under uncontrolled concurrent load; it is not an isolated timing benchmark or an
ARM64 measurement.
